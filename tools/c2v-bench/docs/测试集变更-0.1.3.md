## 原文对齐保证

- `prompt_original == prompt_submitted`；移除历史版本追加的“视频类型”、Anatomy 制作方式和 Kestrel 自由创作文案补充。
- 唯一内容拆分是 Paper Trail：按业务分隔行划为两案，只移除 `1、` / `2、` 和“以下是无图片资源的输入，纯文本”。不把附件文件名和文件大小混入 prompt。
- 从飞书可见文字块导出，仅去掉编辑器零宽占位字符 U+200B，段落按换行保存。保留大小写、标点、措辞和块内空格，不润色、不替换品牌、不补充指令。
- `dataset/v0.1.3/business-text.json` 保存文字证据及单元格/文字块 ID；`prompts/<case>.txt` 保存 UTF-8 原文；每案 `prompt_contract.sha256` 固定提交文本。
- `validate_dataset.py` 从独立文字证据重新提取并核对全部 21 案及 TXT；保存计划和正式提交两个入口再次检查文字和 SHA256，拒绝追加或替换内容。
- Anatomy gate 保留微波炉/放映机两案，使用独立 `experimental_skills` 配置，不写入业务 prompt。配置技能与轨迹中实际使用技能分别记录。

所有新版的实际提交文本都因取消旧前缀而与历史版不同。因此旧成片继续按冻结旧版查看，不能直接计作 0.1.3 的测试结果。若后续要做本版完整横向比较，应由用户授权后运行 20 个 ready 案；本次不执行。

## 素材与评价

沿用已校验的用户输入图片及业务参考；参考模型全部未知，不上传参考成片作为答案。新增月相参考缓存为飞书播放器可见的 360p 预览（54.912 秒），不称为原始上传文件；实际生成时长以 45 秒 prompt 为准。蛋白质/睡眠映射保留用户先前校正。
