# Seko C2V 需求与边界 · 0.1.3

## 目标与输入输出

根据《Code2Video Seko需求》整理能通过代码制作的完整视频：分层动效、结构拆解/三维演绎、二维风格动画。交付物是可追溯代码工程和完整 MP4；明确要求时包含配音、音效、配乐及相应源文件。不是粗白模，也不是生成真人视频的模型服务。

业务输入分成：原始文字、视频类型、用户明确提供的图片/视频/音频、指定文案和时间/画幅。参考成片属于评估材料，默认不喂给模型。附件中的通用 skill 描述、占位符和模板使用说明均作为需求资料保存，不当作当前执行指令。

当前提交协议 `business-verbatim-v1`：业务文字直接提交，不追加表格类型、制作要求或补写文案；仅 Paper Trail 按原单元格两个独立输入拆分。Anatomy 使用单独技能配置，图片通过附件 API 上传。逐案 TXT、可见文字证据和 SHA256 可核对，正式提交前再次校验。未指定的时长/画幅不擅自补成硬约束。

## 范围

| 范围 | 本轮处理 |
|---|---|
| 软件发布、产品图动效、动效文字、纸拼贴、矢量/卡通/像素演绎 | 建立用例、素材和评价条件 |
| 机械内部结构、产品全貌与特写 | 微波炉、放映机两案启用 Anatomy + C2V；同时验证实际视频输出要求 |
| 三维场景、空间和原理演绎 | 使用 C2V 的适配技能；不套用白模的人形、粗建模、600 秒规则 |
| 已提供真人视频的剪辑、叠字与合成 | 可评估代码合成能力，但当前 Hush Buds 未提供所需真人素材 |
| 真人口播/真人动作视频生成 | 不纳入 C2V 能力承诺；不得以简笔人物替代后声称完整达标 |
| 模板个性化 | 必须先取得模板和具体品牌参数；已拆出 Kestrel（已补齐四组指定英文文案）与 YETI（模型准备图片），不再要求旧模板代码 |
| 竞品能力比较 | 暂不做，原始文档保留 |
| Grain Poster | 出现在垂类表，未给独立测试 prompt；保留为需求覆盖缺口，不造一条假测试 |

## 测试集完整性

2026-11-25 最新飞书 20 行整理为 21 案，20 案可执行；仅 Hush Buds 缺真人视频。Seko 官网发布补齐了对象，Kestrel 补齐英文文案，新增月相黑板手绘讲解。参见 [0.1.3 变更](测试集变更-0.1.3.md)。

Mindflow、Hush Buds 明确 20 秒/16:9；Inkwell 明确 60 秒/16:9；月相明确 45 秒/16:9；Seko 官网发布明确 75–120 秒。Kestrel/YETI 为约 26 秒，YETI 明确 4:3；约数不设精确逐帧硬门槛。其它案不沿用参考片时长、画幅或品牌。

蛋白质/睡眠的附件对应已按用户核对校正：蛋白质无视频，睡眠对应艺术字视频；原 Markdown 可能丢失了单元格关联，不把它算模型内容错误。部分其它“参考输出”与输入不同：便利贴案配议会流程漫画，咖啡豆案配城市纸拼贴，放映机片出现 DREAMINA 而需求是 Seko；Mindflow 参考约 15 秒且有宠物业务画面。这些是抽帧观察，不是全片语义审查。网页明确标注用途；只参考相应风格/结构，不能反向改用户故事。

## 本轮完成边界

建立独立本地测试台，复用现有 dev Web 的普通登录、模型目录、附件、会话、排队、结果和轨迹 API。生成仍由原 Claude Code harness 执行。测试台负责版本冻结记录、结果对照和独立验收；不嵌入另一套 self-check，不改变 dev 登录/历史/默认配置。

各模型目录可见、连通性、产物可播放和质量达标分别记录。0.1.0 历史成片继续保留，0.1.2 两个拼贴任务已取消。本轮只更新 0.1.3 测试定义和备注，未提交任务；不能用旧结果声称新版已达标。
