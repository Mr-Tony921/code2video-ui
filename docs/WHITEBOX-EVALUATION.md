# 粗白模评价与交付边界

适用于0.1.16起的Seko和普通白模验证。目标是给后续生成模型提供可读的空间、路径、镜头和剧情关系；不是最终角色动画或精细物理。与旧版对比时使用同一评价标准，并保留原模型审查和原始指标，不回写历史结论。

## 四类结果分别记录

|类别|检查对象|处置|
|---|---|---|
|技术可交付|源码可编译、场景真实可回放、有限坐标、seek一致；要求视频时真实视频可解码|恢复技术有效性，优先保留最后可渲染工程；不伪造空场景|
|原输入结构|Seko片段/分镜/时长/顺序；普通任务的实际显式约束|结构检查与视觉语义分开；普通任务不被强加未要求的Seko结构|
|粗剧情质量|明显路线穿实体、关键主体/结果被遮挡、相对持物漂移/归属错、关键朝向/POV/目的地/前后状态错误|有证据时有限局部修复；未解决照实列出，仍交付可渲染工程|
|允许的粗糙细节|静态持物/站坐/拥抱/支撑交叠及近似间隙、精细手势、步态、微表情、细小姿态差异、轻微擦边|可记录简化，不降为必要结果失败，不追加源码修复|

“待核”单列，不自动通过或判成确认事故。没有逐帧人工检查时必须标明有限证据范围。

## 具体判断

- **移动路径**：人物沿连续路线明显穿过墙、闭门、栏杆或家具不允许；需要几个粗路径点绕行/过实际开口即可。边缘擦碰、静态接触或随人物共同移动的道具，不等同穿路障。真实镜头切换允许离散位置重置；实际移动不能用瞬移掩盖。短切点数值插值风险与画面可见的走路穿墙分开描述。
- **接触与持物**：无需手/杯、臀/椅、脚/地表面精确吻合。先看能否识别谁拿着什么、是否随同移动、何时交给谁/放在哪里。相对距离持续增大、道具独自滑走或归属错误是重点；AABB间隙数值本身不能自动产生语义失败。
- **姿态与朝向**：统一七部件人形，刚性四肢，正常站坐、放松手臂即可。只要粗剧情关系成立，可省略挥手、握拳、步态、精细跪蹲/打斗。主要人物背对交流对象、倒着沿路线移动等影响关系的方向错误需检查；微小角度、眼神、头部表演不要求。静态穿插如果使主体几乎消失或关键关系不可读，按可见性/剧情问题处理，而不是追求非穿插。
- **镜头**：保留必要视角、景别、方向和用户明确锁定的路径；检查事件发生时真实位置和移动终点。装饰性运镜、平滑度不单独追求。人物/关键道具整段被墙挡住、关键交接出画，不能因“粗白模”而放行。非必要前景可局部简化，必要地理和障碍仍保留。
- **因果结果**：简化动作不能省略到达、交接、救援等必要前后变化。姿态不精确但空间关系、归属和结果读得懂即可；不要求精确力学、液体、衣物或肢体动画。

## 修复与交付

初稿最多2次修正，追问一次编辑最多1次修正。首修后只有同一批旧语义问题、没有新回归就停止；第二机会留给技术恢复或真正新回归，并采用更简单的做法。无法确认不自动消耗源修改机会，调用错误不请求模型修复场景。质量有残留不阻止最后可渲染工程和问题说明一起交付。

工程600秒为性能目标，超过时仍完成有限流程。分别记录上传、工程扣实测上传、最终视频渲染和完整等待；模型接口等待可能包含上游排队/传输/推理，不能统称推理时间。性能是否达标不修改视觉质量结论。

## Benchmark和训练筛选

Benchmark分别展示首次候选与有限修复后的渲染成功、结构符合、粗质量、性能、修复请求数和实际采用候选。单个版本的三题实测不能外推400题通过率；换模型对照保留原输入/参考/skill，说明模型预算和渠道差异。

模型自审、自动几何告警、独立画面检查是三个证据来源，不能互相冒充。模型自审不确定但独立事件抽帧确认可读时，两条记录并存。自动几何告警进入待核，不能把所有告警直接计为严重失败；确认的明显路径穿越和剧情不成立才支持相应质量否决。

训练候选允许上述粗糙细节，确认严重事故暂缓，未确定风险另列待核。旧生产白名单不因规则调整而批量自动放宽：须有相应证据复核。评价口径变化带来的“数量增加”与重新生成后真正修好的样本分开统计。
